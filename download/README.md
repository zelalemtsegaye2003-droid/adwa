# Adwa Sec — Startup Application Package (November 2026)

Ten deliverables answering the incubation programme's requirement checklist,
produced from the venture's real platform work (VAPT Center, AD Attack Paths,
bid matrix, compliance engine) and locked financial model.

## Figures used across the package (single source of truth)

`scripts/docgen/numbers.json` (repo) — pre-seed ask ETB 10M (~USD 67K at the
150 ETB/USD planning rate), 18-month runway; revenue ETB 4.02M / 19.26M /
44.64M (2027/2028/2029); costs 9.92M / 21.02M / 36.20M; net −5.90M / −1.76M /
+8.44M; break-even late 2028; subscribers 3 → 12 → 28; FTE 5 → 11 → 20.
Change an assumption in the xlsx Assumptions sheet and re-derive before
editing any quoted figure in the documents.

## Fields only the founder can complete

Placeholders are clearly marked in the CV and the registration letter:
phone, email, education (degree/institution/year), previous employment
entries, certifications. Everything else is final.
